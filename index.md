# Djarvis Privacy Policy

Last updated: September 18, 2026

## About the App

Djarvis ("the App") is a personal automation tool built and operated by an individual developer for his own use. It connects to the developer's own Google account through the Google Drive API to list, read, create and organize files in that Google Drive. The App is not offered to the public and is not distributed to other users.

## Google user data the App accesses

The App accesses Google Drive files and file metadata (such as names, folders and modification dates) of the Google account owner who authorizes it. The App requests only the Google Drive access needed for these features.

## How the data is used

Google user data is used only to provide the features the account owner requests inside the App. The data is not sold, not rented, not published and not used for advertising or for building user profiles. It is not shared with other users.

## Storage and retention

OAuth tokens and any files handled by the App are stored only on devices and services controlled by the account owner. Data is kept only for as long as it is needed for the requested task. Tokens are deleted when access is revoked.

## Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access

The account owner can revoke the App's access at any time at https://myaccount.google.com/permissions and can delete any files the App has created directly in Google Drive.

## Changes to this policy

This policy may be updated from time to time. The date at the top of the page shows the latest revision.
